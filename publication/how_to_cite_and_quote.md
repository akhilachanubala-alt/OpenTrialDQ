# How To Cite and Quote OpenTrialDQ

## Short Project Quote

OpenTrialDQ is an open-source PySpark toolkit for validating public ClinicalTrials.gov datasets with configurable data quality rules.

## Resume / Bio Version

Created OpenTrialDQ, an open-source PySpark toolkit that ingests and flattens public ClinicalTrials.gov study records, applies configurable data quality rules, and produces passed records, failed records, and audit summaries for life sciences analytics workflows.

## LinkedIn About Section Version

I created OpenTrialDQ to demonstrate reusable data quality engineering patterns for public clinical trial datasets. The project uses PySpark, ClinicalTrials.gov API data, configurable validation rules, failed-record handling, and audit summaries to show how life sciences data can be prepared for reliable analytics.

## Technical Citation Format

Chanubala, A. (2026). OpenTrialDQ: PySpark toolkit for configurable data quality checks on public ClinicalTrials.gov datasets. GitHub. https://github.com/akhilachanubala-alt/OpenTrialDQ

## How To Reference The Current Release

Current release tag:

```text
v0.1.0
```

Release notes:

```text
docs/release_notes_v0.1.0.md
```

After a stable GitHub Release is created, use the GitHub Release URL in articles and posts.

## Future DOI Citation

When the project reaches a more mature version, connect GitHub to Zenodo and archive a release. Zenodo will create a DOI that can be used in formal citations.
