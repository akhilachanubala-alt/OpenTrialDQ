# Security Policy

OpenTrialDQ is an educational and open-source data engineering toolkit. It should not be used to process sensitive data without appropriate review and controls.

## Data Safety

Do not open issues or pull requests that include:

- protected health information,
- personally identifiable information,
- employer confidential data,
- proprietary schemas,
- credentials,
- internal screenshots,
- private URLs or tokens.

## Reporting Issues

If you find a security concern in the code, please open a GitHub issue with a minimal public example that does not expose sensitive data.
